## Sentiment Analysis & Competitive Benchmarking

### Project Overview
This project analyses social media sentiment for three smartphone brands: Samsung, Apple, and OnePlus. The objective is to compare positive, negative, and neutral sentiment, identify topic-wise customer concerns, and generate data-driven insights and recommendations.

### Project Objectives
- Compare sentiment across three smartphone brands.
- Identify positive and negative feedback patterns.
- Analyse sentiment across different product and service topics.
- Identify areas that may require improvement.
- Present findings through charts and an executive dashboard.

### Dataset Details
- **Total records:** 120
- **Platforms:** Instagram, X, YouTube, Facebook
- **Brands:** Samsung, Apple, OnePlus
- **Topics:** Camera, Battery, Price, Display, Performance, Software, Customer Service
- **Sentiments:** Positive, Negative, Neutral

**Note:** The dataset contains synthetic practice records created for this project. It does not represent actual customer opinions or real-world brand performance.

### Tools Used
- Google Sheets
- ChatGPT

### Analysis Performed
- Data cleaning and preparation
- Sentiment classification analysis
- Brand-wise sentiment comparison
- Topic-wise sentiment analysis
- Pivot table analysis
- KPI calculation
- Executive dashboard creation
- Insight generation and recommendations

### Key Findings
- Overall positive sentiment: 45.83%
- Overall negative sentiment: 27.50%
- Overall neutral sentiment: 26.67%
- OnePlus recorded the highest negative sentiment rate (34.09%) in the synthetic sample.
- Battery-related feedback had the highest number of negative records.

### Recommendations
- Prioritise investigation of battery-related concerns.
- Review pricing-related feedback.
- Monitor camera and software complaints.
- Collect further feedback after improvements to evaluate changes.

### Project Files
- `social-media-analytics-competitive-intelligence.xlsx` – Analysis workbook and executive dashboard.
- `Social_Media_Analytics_Presentation.pptx` – Project presentation.

### Limitations
This project uses 120 synthetic records for demonstration and learning purposes. The findings cannot be generalised to actual customers or market performance. A larger dataset containing real social media feedback would be required for real-world conclusions.

### Conclusion
This project demonstrates practical skills in data preparation, sentiment analysis, competitive benchmarking, data visualisation, and communicating insights through an executive dashboard.
